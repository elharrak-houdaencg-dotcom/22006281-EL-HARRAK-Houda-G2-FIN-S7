# F9 — Régimes de marché par partitionnement

## Problématique

## Données
- Source : Federal Reserve Economic Data (FRED)
- Série : S&P 500 (SP500)
- URL : https://fred.stlouisfed.org/graph/fredgraph.csv?id=SP500
